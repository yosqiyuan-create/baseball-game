# ドリームプロ野球 by Urushihara

オリジナルの野球ゲームです。iPhone と Mac のブラウザで遊べます。Backbone Pro でも操作できます。

## いまの段階

**段階1：打撃練習**（バージョン 0.1.7）

- コンピューターの投手が投げるボールを、ミートカーソルで打ちます
- 球種は7種類（ストレート・スライダー・カーブ・フォーク・チェンジアップ・シュート・シンカー）
- ミート打ち・強振・バントを切り替えられます
- 打球が飛ぶと、守備の選手が自動で追いかけます。ホームラン・ヒット・アウトを判定します
- ボール・ストライク・アウトのカウントと、打率などの記録が出ます（記録は端末に保存されます）
- 相手の強さ（3段階）、右打ち・左打ち、カーソルの速さを変えられます

## 操作方法

| 動作 | iPhone | Mac | Backbone Pro |
|---|---|---|---|
| カーソルを動かす | 画面をなぞる | 矢印キー | 左スティック・十字キー |
| 打つ | 「打つ」ボタン | Space | Ⓐ |
| ミート／強振の切替 | 「強振」ボタン | Shift | R1 |
| バント | 「バント」ボタン | B | Ⓨ |
| メニュー | ≡ ボタン | Esc | ≡（メニューボタン） |
| 次へ進む | 「打つ」ボタン | Space | Ⓐ |

### 打ち方のコツ

- カーソルの**真ん中**でボールを捉えると、強い打球になります
- ボールがカーソルの**上の方**に当たるとフライ、**下の方**に当たるとゴロになりやすいです
- 打つのが**早い**と引っ張り（右打ちならレフト方向）、**遅い**と流し打ちになります
- 強振はカーソルが小さいかわりに、よく飛びます
- バントは、構えたままボールにカーソルを合わせるだけです（ボタンは押しません）

## GitHub にアップして遊ぶ方法

1. GitHub で新しいリポジトリを作ります（例：`baseball-game`）。公開（Public）にします
2. zip を解凍して、中のファイルとフォルダを**全部**リポジトリにアップロードします
   （「Add file」→「Upload files」に、フォルダの中身をまとめてドラッグ）
3. リポジトリの「Settings」→「Pages」を開きます
4. 「Branch」で `main` と `/ (root)` を選んで「Save」を押します
5. 1〜2分待つと、`https://（あなたのユーザー名）.github.io/baseball-game/` で遊べます
6. iPhone では Safari でこのアドレスを開き、共有ボタン →「ホーム画面に追加」すると、アプリのように全画面で遊べます

## Mac で試す方法（アップする前に確認したい時）

1. zip を解凍したフォルダの中の `start_mac.command` をダブルクリックします
2. ブラウザが自動で開きます
3. 終わる時は、開いたターミナルの画面を閉じます

※「開発元が未確認」と出て開けない時は、`start_mac.command` を右クリック →「開く」を選んでください。
※ `index.html` を直接ダブルクリックしても動きません（ブラウザの決まりのためです）。必ず `start_mac.command` か GitHub Pages で開いてください。

Windows では `start_windows.bat` をダブルクリックします（Python が必要です）。

## Backbone Pro について

- **iPhone で使う時**：iPhone を Backbone Pro に差し込みます（iPhone 15 以降）
- **Mac で使う時**：Mac の「システム設定」→「Bluetooth」で Backbone Pro をつなぎます
- ゲームを開いたら、**どれかのボタンを1回押す**とコントローラーが認識されます（ブラウザの決まりです）
- オレンジ色の Backbone ボタンと画面録画ボタンは、Backbone アプリが使うのでゲームでは使いません
- メニューの「入力テスト」をオンにすると、押しているボタンの番号が画面に出ます。ボタンが効かない時の確認に使えます
- メニューの「コントローラーの振動」をオンにすると振動を試します。ブラウザによっては振動が使えません

## 注意

- iPhone で音が出ない時は、画面を1回タップしてください（iPhone の決まりで、最初のタップまで音が出ません）
- iPhone の消音スイッチがオンだと、音が出ないことがあります
- iPhone で Backbone Pro を使う時は、GitHub Pages のアドレス（https）で開いてください。Mac から同じネットワークで開く方法（http）では、コントローラーが使えないことがあります

## フォルダの中身

| ファイル | 内容 |
|---|---|
| `index.html` | ゲームの画面 |
| `css/style.css` | 画面のデザイン |
| `js/main.js` | ゲームの流れ（投げる・打つ・判定・画面表示） |
| `js/config.js` | 球場の大きさ、選手の能力、球種などの数値 |
| `js/pitching.js` | 投手の球種・コース・球の動き |
| `js/hitting.js` | 打った時の計算（打球の速さ・角度・飛び方、アウトかヒットか） |
| `js/field.js` | 球場の3D |
| `js/characters.js` | 選手の3D（オリジナルのデフォルメキャラ） |
| `js/input.js` | タッチ・キーボード・コントローラーの入力 |
| `js/audio.js` | 効果音（音のファイルは使わず、その場で作っています） |
| `icons/` | アプリのアイコン（バット2本とボール） |
| `manifest.json` | ホーム画面に追加した時の名前とアイコン |
| `lib/` | 3D表示の道具 Three.js（無料・MIT ライセンス） |
